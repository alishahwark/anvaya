# Anvaya data visualization guidelines

Anvaya visualizes only reproducible local data. Current homepage visualizations use counts derived from `data/fixtures/legislative-records.ts`: verified policy records, records requiring review, and verified source-linked milestones.

No GDP, employment, poverty, causal impact, public-opinion, or media-volume charts are shown because those datasets are not present and verified. The public discourse scene is an unavailable state rather than an invented dashboard.

Every future chart must include source institution, URL, publication date, observation period, units, transformation, verification status, and limitations. Any scenario must be labeled as a scenario, not an observation or causal estimate. Key data must have a text/table alternative.
