Anvaya.

Understand what’s changing.

Independent, citizen-first public policy intelligence for India. Not affiliated with the Government of India.

01 · Problem and users

Citizens need status before opinion.

Citizens, journalists, students, and civic organizations need to distinguish proposals, enacted law, later rules, and implementation questions before interpreting impact.

02 · Product and differentiation

A brief, a timeline, and evidence.

Local policy discovery
Milestones with verification state
Official evidence separated from AI
Offline seed and reproducible setup

Differentiation against general search and ChatGPT is a traceable status/evidence boundary—not a verified claim of better outcomes.

03 · Agent architecture

Ask with guardrails.

Portkey calls use only gpt-6-luna. Usage is recorded after successful Responses API calls.

04 · Working application

Verified DPDP evidence, offline first.

Three local MeitY PDFs are identity-checked and indexed into 64 page excerpts. The DPDP page shows assent, G.S.R. 843(E), provision groups, and the separate G.S.R. 846(E) Rules schedule. A real browser smoke test passes.

A real route capture is stored at docs/screenshots/dpdp-policy-page.png; this standalone deck does not yet embed the raster asset.

05 · Tokenomics

Measure before claiming cost.

The app records input, cached input, output, total tokens, provider, model, duration, and status in an ignored JSONL log. Cost per run and 100/10,000-user projections remain unverified until pricing and workload measurements are recorded.

06 · Safety

Evidence is not interpretation.

Only verified event approval can update status. Imported text is delimited as untrusted evidence, citations are checked, and the API refuses to substitute an invented answer on failure. Semantic support remains reviewable rather than claimed as guaranteed.

07 · Measured impact

Do not confuse a passing build with impact.

Engineering checks pass. User time savings, accuracy, usefulness, and user feedback are NOT VERIFIED and are not claimed.

08 · Roadmap

From verified case study to civic utility.

Review the missing December 2025 Rules corrigendum, complete claim-level semantic review, add broader government-source ingestion, measure benchmark quality and cost, and embed the real screenshot asset in the final standalone deck.
