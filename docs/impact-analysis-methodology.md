# Impact analysis methodology

Impact output is analysis, not legal fact. The impact agent receives one selected policy register record and must return stakeholder groups with:

- potential benefits;
- potential costs;
- administrative/compliance burden;
- distributional considerations;
- possible unintended consequences;
- implementation challenges;
- evidence gaps.

The prompt prohibits numerical forecasts unless the supplied evidence contains them. Because the current local records are unverified and do not contain document-level statutory text, current DPDP impact output is conditional and explicitly identifies the missing Act text, rules, commencement notices, and implementation evidence.

No stakeholder outcome is treated as a measured result. A future verified import should attach provision/page citations to each impact claim before presenting it as source-backed analysis.
